# Hotel-booking-Data-analysis-Dashboard-project(Using-MS-Excel)
## Project Objective
Analyze hotel booking trends and customer behavior.
Identify factors affecting booking cancellations.
Compare performance between different hotel types.
Examine seasonal booking patterns.
Generate actionable insights through visual dashboards.
Demonstrate Excel-based data analysis and reporting skills.
## Dataset used
- <a href= "https://github.com/malikma292/Data-analysis-Dashboard/blob/main/Project1.xlsx">Dataset</a>
## Dataset Information
The dataset contains hotel booking records and includes various attributes such as:
Hotel Type
Booking Date
Arrival Year
Arrival Month
Lead Time
Number of Guests
Meal Type
Market Segment
Customer Type
Room Type
Booking Status
Cancellation Information
Special Requests
Country Information
## Tools & Technologies Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
Data Cleaning Techniques
Dashboard Design
Statistical Analysis
## Data Preparation Process
Before analysis, the dataset was cleaned and prepared by:
Removing duplicate records.
Handling missing values.
Formatting inconsistent data.
Verifying data accuracy.
Creating calculated fields where required.
Organizing data for efficient reporting.
## Analysis Performed
1. Booking Trends Analysis
Monthly booking distribution.
Year-wise booking comparison.
Peak and off-peak seasons identification.
2. Cancellation Analysis
Total cancellation rate.
Cancellation trends by hotel type.
Impact of lead time on cancellations.
3. Customer Segmentation
Customer type distribution.
Market segment analysis.
Geographic customer analysis.
4. Hotel Performance Analysis
Comparison between Resort Hotels and City Hotels.
Booking volume evaluation.
Occupancy-related insights.
5. Special Requests Analysis
Relationship between guest requests and booking outcomes.
Customer preferences evaluation.

✅ Customer Segmentation Reports

✅ KPI Summary Metrics

✅ Easy-to-understand Visual Insights

## Key Insights
Some important findings from the analysis include:
Certain months show significantly higher booking volumes.
Longer lead times tend to have higher cancellation rates.
Customer booking behavior varies across hotel types.
Specific market segments contribute more bookings than others.
Seasonal trends strongly influence hotel demand.
## Project Outcomes
This project demonstrates how Excel can be used as a powerful business intelligence tool to:
Transform raw data into meaningful insights.
Support decision-making processes.
Identify business opportunities and risks.
Create professional dashboards without advanced BI software.
